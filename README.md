# 📊 Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, starting from raw data loading and cleaning to SQL analysis, data visualization, and presentation.

The project uses Python for Exploratory Data Analysis (EDA) and data cleaning, SQL for querying and analysis, and Power BI for creating an interactive dashboard. A project report and presentation were also created to summarize the findings and insights.

## 🔄 Project Workflow

### 1. Data Loading

The dataset was loaded into Python using Pandas.

### 2. Exploratory Data Analysis

EDA was performed to understand:

- Dataset structure
- Important variables
- Missing values
- Duplicate records
- Data distributions
- Key trends and patterns

### 3. Data Cleaning

The data was cleaned by:

- Handling missing values
- Removing duplicate records
- Correcting data types
- Standardizing values
- Preparing the dataset for analysis

### 4. SQL Analysis

The cleaned data was imported into the database.

SQL queries were used to perform:

- Aggregations
- Filtering
- Grouping
- Joins
- Subqueries
- Window functions
- Business-related analysis

### 5. Power BI Dashboard

The analyzed data was connected to Power BI to create an interactive dashboard.

The dashboard includes:

- Key Performance Indicators (KPIs)
- Charts and graphs
- Filters and slicers
- Trend analysis
- Business insights

### 6. Report & Presentation

The major findings and insights were documented in a project report and presented using PowerPoint/Gamma.
